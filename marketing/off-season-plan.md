# Off-Season Marketing Plan — Beach Bliss Retreat (Aug–Dec)

## Why this window is soft
Not one slow season — three, each needing different messaging:
- **Aug–Sep**: heat, humidity, back-to-school. Gulf Coast FL's quietest stretch.
- **Aug–Nov**: hurricane season. Guests hesitate to book because of storm risk, not price.
- **Nov–Dec**: picks back up for Thanksgiving/Christmas family travel, before snowbird season (Jan+) takes over.

Discounting price alone only addresses the first. The hesitation in Aug–Nov is about *risk*, not cost — so flexibility sells better than a bigger percentage off.

## The angle (already reflected in the new "Specials" section on the site)
1. **Extended-stay savings** — pitch weekly/monthly stays to remote workers, not just nightly discounts.
2. **Storm-season flexibility** — free rebooking/flexible cancellation Aug–Nov removes the actual objection.
3. **Holiday family-gathering pitch** — sleeps 6, dock, kayak, fishing gear — lean into this Nov–Dec.

## What has to happen on Airbnb/VRBO (the site can't do this — it only links out to the listing)
- [ ] Turn on/increase **weekly (~15-20%) and monthly (~25-30%) discounts** for Aug–Dec dates in the Airbnb host dashboard (Pricing → Discounts). This is a native Airbnb feature, no code needed.
- [ ] Set cancellation policy to **Flexible** (or add a pinned message about storm-related rebooking) for Aug–Nov reservations specifically.
- [ ] Review Smart Pricing floor/ceiling so it doesn't quietly undercut the off-season rate you actually want.
- [ ] Send a one-time message to past guests (Airbnb "message past guests" tool) in late July with the fall offer.
- [ ] Refresh listing photos to include a fall/off-peak-feeling shot if you have one (empty beach, sunset).

## Social (low effort, do 1x/week Aug–Dec)
- Quiet-beach photo + "book without the crowds" caption.
- Remote-work angle: photo of the WiFi/dining table setup, caption aimed at digital nomads.
- Storm-season reassurance post once, pinned, restating the flexible-rebooking policy in plain language.
- Late Oct: start posting toward the Nov/Dec holiday-gathering angle specifically (families planning Thanksgiving/Christmas trips book 6-8 weeks out).

## Measurement
Airbnb host dashboard already tracks views → bookings conversion by date range. Check it monthly Aug–Dec:
- If views are flat but bookings are down → it's a price/policy problem (fix via the discount/cancellation settings above).
- If views are also down → it's a visibility problem (photos, title, social pushes need more work), not a pricing one.
